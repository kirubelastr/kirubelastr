## About

I build full-stack web applications with Next.js, TypeScript and Payload CMS, and deploy most of them on Cloudflare Workers with D1, R2 and KV. I've shipped e-commerce stores, marketplaces, online learning platforms and other web apps, often connected to Telegram bots and live chat.

I'm open to collaborating on open-source projects.

## Featured work

### Kiray

`Private repository`

A bilingual (English and Amharic) rental marketplace for Ethiopia. Shops and service providers list what they rent out, and renters browse, compare and request callbacks. It has separate accounts and dashboards for shops, service providers and renters, along with subscriptions and Chapa payments, and is deployed as a single Cloudflare Worker.

**Built with:** Next.js · Payload CMS · Cloudflare Workers, D1, R2, KV · next-intl · Chapa

### [ecommerce-with-stripe](https://github.com/kirubelastr/ecommerce-with-stripe)

An online store with a shopping cart, Stripe checkout and a content-managed storefront.

**Built with:** Next.js · Payload CMS · PostgreSQL · Stripe

### [react-next-web](https://github.com/kirubelastr/react-next-web)

A responsive marketing site.

**Built with:** Next.js · React · Tailwind CSS
